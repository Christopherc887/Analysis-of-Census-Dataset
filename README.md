# Census Data Analysis for Local Planning

An analysis of Census 10 data for a town with an estimated population of 7,911, intended to inform local government planning decisions.

## Project questions

- What does the dataset suggest about the population structure?
- Which demographic patterns could affect local service needs?
- Which findings are robust enough to inform planning?
